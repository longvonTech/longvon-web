LONGVON · 智能戒指制造商 · OEM/ODM

智能戒指 SDK 与云端 API（合作伙伴）

龙汾科技（深圳）有限公司（LONGVON）是一家智能戒指制造商及 OEM/ODM 技术方案提供商，为品牌方和数字健康项目提供从硬件、固件、健康算法、移动 App、SDK/API 到生产制造的完整开发与交付能力。 LONGVON（龙汾科技）是技术制造商与 OEM/ODM 提供方，MATEYOU 是其智能戒指产品品牌。

SDK 概览

LONGVON 可为品牌与数字健康团队提供智能戒指 SDK 对接能力，用于客户自有 App 或其他应用集成。开通方式为项目制合作，而非公开自助门户。

100Hz PPG 原始数据

对合格 OEM/ODM 合作伙伴，可讨论 100Hz PPG 原始数据 获取路径。交付格式、采样、缓存与授权以技术范围为准。

传感器数据接入

除 PPG 外，还可按硬件代际与项目约定讨论温度、运动等相关信号。可用信号与采样率取决于硬件代际与项目协议。

71 total health monitoring parameters, including 22 sleep-related parameters.公开指标仅供健康参考，不构成医学诊断。

健康数据集成

合作伙伴可规划 App 侧与云端侧的睡眠、呼吸及其他健康监测输出集成。集成深度结合产品架构与合规需求评估。

SDK 与云端 API

  • 设备 / 配套 SDK（含客户自有 App 集成评估）
  • 云端 API 选项（数据接入与算法服务）
  • 约定范围内的固件协作
  • 按项目定义的技术支持窗口

客户自有 App 集成

支持客户自有 App 集成。可行性、工作量与周期取决于技术栈、目标平台与所需指标，在技术咨询中评估。

算法服务与授权边界

LONGVON 为许多健康指标提供云端算法服务。部分能力可能在端侧运行，另一些依赖 LONGVON 云端。算法授权与云服务费用按合作模式确定。不承诺全部算法可在客户硬件完全离线运行。

  • SDK：对接与数据通路
  • 算法授权：可用指标 / 模型范围
  • 技术支持：约定窗口内的集成协助
  • 云服务：云端算法与数据接口（单独约定）

技术合作流程

  1. 需求沟通与保密约定
  2. 范围：原始数据、端侧能力、云端能力、App 归属
  3. 算法授权与环境
  4. 集成支持窗口
  5. 商务授权 / OEM 协议

常见问题

是否提供公开自助 SDK 下载？

否。SDK 与云端 API 在 OEM/ODM 或技术合作项目中开通，范围按项目约定。

是否可获取 100Hz PPG 原始数据？

对符合条件的 OEM/ODM 合作伙伴，可按项目评估 100Hz PPG 原始数据获取路径。

是否承诺全部算法可在客户硬件离线独立运行？

否。许多健康指标通过 LONGVON 云端算法服务提供；端侧与云端分工按项目定义，不得理解为全部算法均可离线运行。

是否提供无限制的通用蓝牙协议？

否。接口按项目文档提供；无限制蓝牙协议不是默认公开承诺。

是否支持客户自有 App 集成？

支持。客户自有 App 通过 SDK/API 集成是可行合作模式，需在技术咨询中评估可行性与工作量。

SDK、算法授权、技术支持与云服务如何区分？

SDK 提供设备对接与数据通路；算法授权决定可使用的指标/模型范围；技术支持按约定窗口提供；云服务承载云端算法与数据接口，费用与开通范围按合作模式单独约定。
