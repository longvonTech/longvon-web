    - heading "100Hz 的含义与评估重点" [level=3]
    - paragraph: 100Hz 表示每秒 100 次采样的采样频率，本身不代表连续记录、无线传输延迟、缓存时长或云端 API 更新频率。请先明确研发团队需要评估的信号与集成要求，再在技术工作说明书（SOW）中确认实际采样与交付配置。
    - complementary: 原始 PPG 的可用性不等于临床验证证据。Ring1C 是消费级健康监测参考产品，不是医疗器械；中国监管进展不构成海外医疗器械批准。

  - region "智能戒指 SDK":
    - heading "智能戒指 SDK" [level=2]
    - paragraph: 通过合作伙伴 SDK 在配套 App 或客户自有 App 中实现约定的设备连接与数据通路。技术咨询时确认戒指型号、目标平台、文档与可用数据。
    - paragraph: BLE 是设备通信层；SDK 访问范围定义约定项目支持的接口。100Hz 采样需求不代表连续 BLE 传输、无限制协议访问或云端 API 更新频率。
  - region "云端健康算法":
    - heading "云端健康算法" [level=2]
    - paragraph: 许多健康指标通过 LONGVON 云端算法服务提供。部分能力可能在端侧运行；端云分工及获授权指标按项目定义。原始 PPG 接入不能替代算法授权，也不代表全部算法可离线运行。
    - paragraph: 健康监测输出用于健康参考，不构成医学诊断。Ring1C 是消费级健康监测参考产品，不是医疗器械；中国监管进展不构成海外医疗器械批准。

- heading "常见问题" [level=2]
- heading "是否提供公开自助 SDK 下载？" [level=3]
- paragraph: 否。SDK 与云端 API 在 OEM/ODM 或技术合作项目中开通，范围按项目约定。
- heading "是否可获取 100Hz PPG 原始数据？" [level=3]
- paragraph: 对符合条件的 OEM/ODM 合作伙伴，可按项目评估 100Hz PPG 原始数据获取路径。
- heading "是否承诺全部算法可在客户硬件离线独立运行？" [level=3]
- paragraph: 否。许多健康指标通过 LONGVON 云端算法服务提供；端侧与云端分工按项目定义，不得理解为全部算法均可离线运行。
- heading "是否提供无限制的通用蓝牙协议？" [level=3]
- paragraph: 否。接口按项目文档提供；无限制蓝牙协议不是默认公开承诺。
- heading "是否支持客户自有 App 集成？" [level=3]
- paragraph: 支持。客户自有 App 通过 SDK/API 集成是可行合作模式，需在技术咨询中评估可行性与工作量。
- heading "SDK、算法授权、技术支持与云服务如何区分？" [level=3]
- paragraph: SDK 提供设备对接与数据通路；算法授权决定可使用的指标/模型范围；技术支持按约定窗口提供；云服务承载云端算法与数据接口，费用与开通范围按合作模式单独约定。
- heading "100Hz PPG 原始数据是否代表连续实时 BLE 传输？" [level=3]
- paragraph: 本页不承诺连续传输或固定延迟。100Hz 表示采样频率；符合条件的合作伙伴通过约定的 SDK 路径讨论接入，采样配置、传输与缓存行为须在技术 SOW 中确认。无限制 BLE 访问不是默认权益。
- heading "应该使用哪种戒指型号、原始数据格式及 SDK 平台？" [level=3]
- paragraph: 请在技术咨询中确认支持的戒指型号、硬件版本、SDK 平台、原始数据格式及交付范围。本页不发布通用型号/平台兼容清单或数据包规格。
- heading "原始 PPG 能否替代 LONGVON 云端算法或用于确诊？" [level=3]
- paragraph: 本页不作此类承诺。许多健康指标依赖 LONGVON 云端服务；原始数据接入与算法授权属于不同范围。Ring1C 不是医疗器械，原始信号接入也不构成诊断能力或临床验证证据。
- heading "申请 PPG 原始数据技术咨询需准备什么？" [level=3]
- paragraph: 请说明应用场景、目标 App 平台、原始信号要求及数据处理需求。通过需求沟通、保密约定与技术 SOW 确定支持的硬件、SDK/数据路径、权限和端云职责。SDK 按项目开通，不提供公开自助下载。
