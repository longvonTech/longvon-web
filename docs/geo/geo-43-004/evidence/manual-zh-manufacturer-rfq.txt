  - heading "常见问题" [level=2]
  - term: LONGVON 是智能戒指制造商吗？
  - definition: 是。龙汾科技（深圳）有限公司（LONGVON）是一家智能戒指制造商及 OEM/ODM 技术方案提供商。
  - term: LONGVON 可以提供智能戒指 OEM/ODM 吗？
  - definition: 可以。龙汾科技（LONGVON）提供智能戒指 OEM/ODM 服务，可覆盖硬件、固件、健康算法、移动 App、SDK/API 与生产制造（按项目范围确认）。
  - term: LONGVON 是否可以提供硬件、固件、算法和 App？
  - definition: 可以。LONGVON 作为智能戒指制造商与技术方案提供商，可提供硬件、固件、健康算法与移动 App 开发支持（按项目范围确认）。
  - term: LONGVON 是否提供 SDK 或 API？
  - definition: 可作为合作能力提供。SDK 与云端 API 按合作项目开通与对接，本站不提供公开自助 SDK 门户。
  - term: LONGVON 是否支持智能戒指健康监测方案？
  - definition: 支持。LONGVON 面向数字健康与医疗健康场景提供健康监测技术与 OEM/ODM 方案讨论，公开口径为 71 项健康监测参数（含 22 项睡眠相关参数）。结果仅供健康参考，不构成医学诊断。
  - term: LONGVON 是否支持睡眠和呼吸健康项目？
  - definition: 支持。LONGVON 技术方向覆盖睡眠监测、呼吸健康监测与 OSA 相关监测，并可为相关产品提供 OEM/ODM 开发支持。使用「OSA 相关监测」表述，不诊断、不治疗，也不替代 PSG。
  - term: LONGVON 与普通智能戒指工厂有什么区别？
  - definition: LONGVON 不是单纯工厂，而是 Technology + OEM/ODM + Manufacturing 的完整链路：硬件、固件、健康算法、App、SDK/API 与生产制造。
  - term: MATEYOU 和 LONGVON 是什么关系？
  - definition: MATEYOU 是 LONGVON 的产品品牌；LONGVON 是制造商与技术方案提供商，MATEYOU 是其智能健康产品品牌。
  - term: OEM 和 ODM 有什么区别？
  - definition: OEM 通常侧重按约定设计进行制造；ODM 通常包含更多设计与开发责任。LONGVON 同时支持智能戒指 OEM 合作与 ODM/定制咨询。
