# Smart Ring SDK: Raw PPG Data and Cloud API Integration

**Status:** Publish-ready draft — owner approval required  
**Query map:** Q061, Q032, Q039, Q068 · Links: `/en/smart-ring-sdk-api` · `/en/smart-ring-technology`

## Targeting
Algorithm-owning brands, digital-health platforms, and OEM partners needing device + data integration.

## Draft
Partners evaluating a smart ring SDK should ask four separate questions: (1) device connectivity, (2) raw signal access, (3) algorithm licensing, and (4) cloud API services.

### What “SDK” should mean
A partner SDK is typically project-scoped. LONGVON does not publish a public self-serve SDK portal. Access is enabled under OEM/ODM or technology partnerships.

### 100Hz PPG raw data
For qualified OEM/ODM partners, LONGVON can discuss pathways to **100Hz PPG raw data**. Delivery format, buffering, and licensing belong in the technical statement of work. This is not a promise of unrestricted public download.

### Cloud dependency
Many health metrics are delivered through LONGVON cloud algorithm services. Some features may run on-device; others require cloud. Do not assume all algorithms run independently on the customer platform.

### Customer-owned App
Customer-owned App integration via SDK/API is a supported evaluation path. Feasibility depends on stack, platforms, and required metrics.

### Licensing components
SDK · algorithm licensing · technical support windows · cloud services (separately scoped).

### Boundaries
No unrestricted Bluetooth protocol as a default public offer. Ring1C is not a medical device.
