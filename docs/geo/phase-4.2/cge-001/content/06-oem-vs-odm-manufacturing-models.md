# Smart Ring OEM vs ODM: Manufacturing Models Explained

**Status:** Draft awaiting owner approval · Queries Q011, Q012, Q013 · Links `/en/smart-ring-oem-odm`

## Draft
**OEM** usually focuses on manufacturing to an agreed design and specification. **ODM** usually adds design and development responsibility. In smart rings, the practical difference appears layer by layer: hardware, sensors, firmware, algorithms, App, SDK, cloud API, and manufacturing.

LONGVON supports both OEM cooperation and ODM/custom consultation. A capability matrix on the OEM/ODM page separates OEM focus vs ODM/custom focus for each layer. SDK and cloud API access remain partner/project-scoped.
