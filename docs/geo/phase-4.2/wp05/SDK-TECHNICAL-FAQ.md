# SDK Technical FAQ (Draft)

Status: REVIEW · 2026-11-10T13:00:47Z

**Q: Do you provide raw PPG?**  
A: 100Hz PPG raw data access can be discussed for qualified OEM/ODM partners (project scope).

**Q: Can algorithms run fully on our hardware offline?**  
A: Do not assume yes. LONGVON provides cloud algorithm services; on-device vs cloud split is defined per project. We do not claim all algorithms are offline-capable.

**Q: Is there a public SDK download?**  
A: No public portal. SDK is enabled under partnership.

**Q: Can we use our own App?**  
A: Yes — customer-owned App integration via SDK/API is a supported model.

**Q: Bluetooth protocol?**  
A: Interfaces are provided as documented for the project. Unrestricted protocol access is not a default public claim.
