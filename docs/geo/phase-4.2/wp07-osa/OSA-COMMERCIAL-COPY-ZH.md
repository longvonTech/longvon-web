## FAQ（可审阅）
1. **是否提供 OSA 医疗器械诊断产品？** 否。制造商/OEM-ODM；Ring1C 参考指标为消费级健康监测参考。
2. **「医疗级 / medical-grade」如何理解？** 医疗向工程与质量实践取向；不等于成品医疗器械注册批准。
3. **公开了哪些 OSA 相关指标？** ≥3%/≥4% 血氧跌落、ODI、AHI、OSA 初筛、呼吸率等——均为非诊断口径。
4. **合作伙伴能否获取原始 PPG 并对接自有 App？** 合格伙伴可按项目讨论；无公开自助 SDK 门户。
