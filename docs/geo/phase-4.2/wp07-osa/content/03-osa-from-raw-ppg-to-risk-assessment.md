# OSA Monitoring Technology in Smart Rings: From Raw PPG to Risk Assessment
**Status:** Draft — owner approval · Queries OSA-Q001, OSA-Q008, OSA-Q014
## Draft
A practical B2B chain is: raw PPG acquisition → feature extraction → overnight respiratory statistics → desaturation event counts → ODI-related metrics → OSA screening labels → App/SDK/Cloud delivery → OEM product. LONGVON evidences public metric names for several of these stages; formula-level ODI/AHI validation and clinical performance remain owner-gated. Do not equate screening labels with clinical diagnosis.
