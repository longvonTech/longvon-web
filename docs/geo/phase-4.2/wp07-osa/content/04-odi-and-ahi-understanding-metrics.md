# ODI and AHI: Understanding Sleep Respiratory Monitoring Metrics
**Status:** Draft — owner approval · Queries OSA-Q007 · Strict boundary
## Draft
ODI counts oxygen desaturation events per hour; AHI counts apnea/hypopnea events per hour on clinical studies using airflow/effort channels. Wearable AHI-style outputs are estimates/monitoring metrics unless a cleared clinical pathway says otherwise. LONGVON publishes ODI and AHI as monitoring metrics and separately publishes ≥3%/≥4% SpO2 drop statistics. Exact ODI definition used in product algorithms requires owner specification before detailed marketing. Never present estimated AHI as PSG AHI without validation evidence.
